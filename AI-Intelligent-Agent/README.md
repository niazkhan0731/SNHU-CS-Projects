# 🏴‍☠️ Pirate Intelligent Agent – Reinforcement Learning Project

## 🌍 Overview
This project was completed as part of my **Emerging Trends in Computer Science** course. It demonstrates the application of **reinforcement learning (RL)** and **neural networks** to solve a real-world inspired problem. Specifically, I developed a deep Q-learning–based intelligent agent capable of navigating an 8x8 grid environment to locate hidden treasure while maximizing rewards and avoiding penalties.  

The final artifact for this project is a **Jupyter Notebook** (`TreasureHuntGame.ipynb`) that contains the full implementation of the Q-training algorithm, training results, and supporting code. This repository serves as both a **technical showcase** and a **reflection** on the skills gained through this work.

---

## ⚙️ Project Details

### 📂 Code Provided
- **`TreasureEnvironment.py`** – Defined the 8x8 grid environment, rewards, penalties, and game rules.  
- **`GameExperience.py`** – Implemented experience replay functionality to store and sample previous state-action-reward sequences for more stable training.  
- **Starter Jupyter Notebook** – Included a basic structure and placeholders for training and evaluating the agent.

### 💡 Code I Created
- Implemented the **deep Q-learning algorithm** inside `TreasureHuntGame.ipynb`.  
- Designed and trained a **neural network model** to approximate Q-values.  
- Built the **training loop** with epsilon-greedy exploration and integrated experience replay.  
- Tuned hyperparameters such as **learning rate, discount factor, and exploration decay** to achieve convergence.  
- Validated the agent’s performance, achieving a **100% win rate** after sufficient training episodes.  
- Documented progress with training logs and screenshots for submission.
